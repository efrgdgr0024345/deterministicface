Preserve typed error codes without echoing the full fingerprint.

Test all checked-in vectors unchanged; lengths 1 and 8160; label/index boundaries; malformed input; leading zeros; input immutability; independent returned buffers; call-order repeatability; and injected-word rejection boundaries. The core must not reference the browser DOM, filesystem, network, clock or ambient random functions.
